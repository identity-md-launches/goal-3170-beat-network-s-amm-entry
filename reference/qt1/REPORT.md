## Reference (the Python below, `qmref.py`)

The reference combines two parts, using only the standard library:
- **Filter:** trim-2's filter, which is port-3's `standalone.Coarse` code verbatim. To this I added real.py's `synced` flag: it is reset at each new step and set when an own retail fill moves the rival estimate.
- **Fee rule:** real.py's `RealPolicy.lookup` (qm variant). It reads the sd level from `sqrt(v)*1e4`, the posterior sd after the update, exactly as real.py passes it. It uses tag `0c` in phase 0 and phase + `s`/`c` otherwise. It interpolates bilinearly at levels k and k+1, then linearly in sd. The column axis is `_pos2` over pol_mid's `W2L`.

The decoded tables come from a pure-Python port of qm-spline's decoder: Cox–de Boor at the grid nodes, clamp at 0, A = w + F rounded to 6 decimals, B = point mirror. They are **identical (max |diff| = 0) to qm-spline's numpy decoder JSON** over all 10 tables.

The init fee follows real.py: `init()` uses the *plain* `pol_mid` table at (0,0,0), which is 0.002823606104386589 each, not a qm table. The contract returns 2823606104386589 WAD.

**Check values reproduced:** the reference gives 443.101741 / 571.454483 / 525.908441 on seeds 10000..10002, every printed digit equal to qm-spline's values.

**Gate Q** is qm-spline's: paired loss 0.0632 (se 0.0072, n = 2048) against the full qm tables. I did not re-run it, because the reference is exactly real.py over those decoded tables, as the identical tables and check values above show.

## Contract design (generated by `gen.py` from the blob and trim-2's source)

- The following are trim-2's source byte for byte: `ln`, `exp`, `root`, `pdf`, `cdf`, `trunc`, `update` and `afterInitialize` (apart from the init constant). The storage packing in `afterSwap` is also trim-2's.
- The synced flag is stored in bit 255 of slot 2, and `cnt` is read as `s2>>192 & 0xffffffff`.
- The net is replaced by the qm-spline lookup:
  - **Coefficients:** 4,896 int16 values, stored as `c + 32768` in 16 lanes per 32-byte word. That makes 306 words of PUSH32 immediates, returned by 20 small binary-tree functions (`cw0..cw19`) under one dispatcher `cw`.
  - **Basis values:** computed at runtime by Cox–de Boor (6 divisions per node). The knot vectors are packed as 16-bit lanes (2 words per axis per table). There are no basis tables.
  - **sd axis:** a single cubic with no interior knots, so it is a Bernstein basis. I use the exact integer weights C(3,s)·l^s·(7−l)^(3−s), which sum to 343.
  - **Lookup rule** (qm-spline's): compute F at the 4 grid nodes × 2 sd levels, clamp each at 0, interpolate bilinearly, then linearly in sd.
  - **Ask side:** fee input = F(pw,p2) + (w_q − w). Here w_q is the clamped row's offset, so the input is a − w as real.py computes it.
  - **Bid side:** F is taken at the mirror point (320 − pw, last − p2), and the fee input is F + (w − w_q).
  - **Fee conversion:** trim-2's (`U − exp(−x/10000)` if x > 0, clipped to [0, 10%]).
- **Contract rules:** no assembly; `contract Strategy is AMMStrategyBase`; Taylor (gtmcknight) credited in the header. `amm-match validate`: `Strategy 'TaylorGaussianQMSpline' validated successfully!`
- **Compile issue fixed:** a single 306-leaf nested `if` tree made solc 0.8.24 (viaIR) segfault at the default 8 MB stack. It compiled only with an unlimited stack. Splitting the tree into 20 sub-functions fixed it, and the shipped source compiles at the default stack.
- **Gas fix:** the first working version accumulated into dynamic memory arrays. It cost about 72–100k gas per surface (pyrevm peak 288,854). The shipped version contracts each coefficient stripe straight into stack and fixed-index memory accumulators, at about 34–43k per surface.

## Notes and limits

- **Engine headroom:** the contract costs about twice trim-2's gas, because each callback evaluates two spline surfaces at about 35–43k each. More headroom would come from two cheaper steps: binary search for knot spans (about 2.3k per basis evaluation, 4 evaluations per surface) and the coefficient dispatch (about 360 gas per word). I did neither, because both targets were already met.
- **Fee error:** spline values carry fixed-point rounding (WAD bases, integer divisions in Cox–de Boor). Against the Python decoder at 40 test points (20 grid nodes and 20 random interior points with random sd fraction, across the 5 tables), the max |diff| of the surface is 1.9e-11 bps. Gate F measures the combined error at 5.8e-6 bps.
- **Scope of the engine figures:** only seeds 9535000..9535127 were used on the engine, once per strategy. Replica results do not convert to board scores.
- **Not included here because of the 64 KB limit:** the generator `gen.py`, the Gate F harness (`check.py`, port-3's `check.py` with the reference swapped in and traces cached), the engine harness (port-3's `engine.py` with the seed range changed) and the unit-test scaffolding. The contract and reference below are complete.

## Python reference (complete; `qmref.py`, stdlib only, needs the 10,167-byte QMS1 blob from qm-spline's artifact)

As a replica policy: `replica2.run(seed, QMRef('blob.bin'))`.

rule over the DECODED qm-spline tables (QMS1 blob, sha256 3ac7cb88...). Standard library only.
usage: from qmref import QMRef; QMRef('blob.bin') is a replica2 policy (wants_j).

"""
import math, struct

SIG2 = .000945 ** 2
LD_M, LD_S = math.log(11.12e-4), 1.176
INIT = 0.002823606104386589
MAXF = 0.1


def phi(x): return math.exp(-.5 * x * x) / 2.5066282746310002
def Phi(x): return .5 * (1 + math.erf(x / 1.4142135623730951))


def trunc(m, v, lo, hi):
    if v <= 0: return float(lo <= m <= hi), m, 0.
    sd = math.sqrt(v); a = (lo - m) / sd; b = (hi - m) / sd; z = Phi(b) - Phi(a)
    if z < 1e-12: return z, lo if m < lo else hi, v * .25
    pa, pb = phi(a), phi(b); r = (pa - pb) / z
    return z, m + sd * r, max(0, v * (1 + (a * pa - b * pb) / z - r * r))


def parse(blob):
    o = [0]
    def rd(fmt):
        v = struct.unpack_from('<' + fmt, blob, o[0]); o[0] += struct.calcsize('<' + fmt); return v
    assert blob[:4] == b'QMS1'; o[0] = 4
    form, ntab, nw, w0, h, ns = rd('BBHHBB'); assert form == 3
    S = list(rd('%dB' % ns)); n2 = rd('B')[0]; W2L = list(rd('%dh' % n2)); fb = rd('B')[0]
    tabs = []
    for _ in range(ntab):
        nr, nc, nk = rd('BBB')
        kr = list(rd('%dH' % (nr - 4))); kc = list(rd('%dH' % (nc - 4))); ks = list(rd('%dH' % (nk - 4)))
        assert nk == 4 and not ks
        tabs.append([nr, nc, nk, kr, kc])
    for t in tabs:
        t.append(list(rd('%dh' % (t[0] * t[1] * t[2]))))
    assert o[0] == len(blob)
    return dict(NW=nw, W0=w0, H=float(h), S=[float(s) for s in S], W2L=[float(v) for v in W2L], FB=fb, tabs=tabs)


def basis(knots, x):
    """all cubic B-spline basis values at x (Cox-de Boor recursion), right end included"""
    t = knots; n = len(t) - 4
    B = [1.0 if t[m] <= x < t[m + 1] else 0.0 for m in range(len(t) - 1)]
    if x >= t[-1]:
        last = max(m for m in range(len(t) - 1) if t[m] < t[m + 1]); B = [0.0] * (len(t) - 1); B[last] = 1.0
    for d in range(1, 4):
        Bn = [0.0] * (len(t) - 1 - d)
        for m in range(len(t) - 1 - d):
            a = t[m + d] - t[m]; b = t[m + d + 1] - t[m + 1]
            if a > 0: Bn[m] += (x - t[m]) / a * B[m]
            if b > 0: Bn[m] += (t[m + d + 1] - x) / b * B[m + 1]
        B = Bn
    return B[:n]


def surfaces(P):
    """F[t][level][row][col] = max(0, spline) at the grid nodes, in bps"""
    out = []
    for ti, (nr, nc, nk, kr, kc, C) in enumerate(P['tabs']):
        ncol = 2 * P['FB'] + 1 if ti == 0 else len(P['W2L'])
        Kr = [0.0] * 4 + [v / 64 for v in kr] + [P['NW'] - 1.0] * 4
        Kc = [0.0] * 4 + [v / 64 for v in kc] + [ncol - 1.0] * 4
        Ks = [0.0] * 4 + [len(P['S']) - 1.0] * 4
        Br = [basis(Kr, i) for i in range(P['NW'])]; Bc = [basis(Kc, j) for j in range(ncol)]
        Bs = [basis(Ks, l) for l in range(len(P['S']))]
        F = []
        for l in range(len(P['S'])):
            D = [[sum(Bs[l][s] * C[(s * nr + r) * nc + c] for s in range(nk)) / 8.0 for c in range(nc)] for r in range(nr)]
            E = [[sum(D[r][c] * Bc[j][c] for c in range(nc)) for j in range(ncol)] for r in range(nr)]
            F.append([[max(0.0, sum(Br[i][r] * E[r][j] for r in range(nr))) for j in range(ncol)] for i in range(P['NW'])])
        out.append(F)
    return out

            elif is_arb: self.m, self.v = lp, 0.
            else: self.m, self.v = mt, vt

        self.fb, self.fa = min(MAXF, max(0.0, fb)), min(MAXF, max(0.0, fa))
        return fb, fa
